# fillcron

Fill and reshape cron text streams with deterministic transforms.

**Site:** https://theworker02.github.io/fillcron/

## Install / run

```bash
git clone https://github.com/theworker02/fillcron.git
cd fillcron
node src/cli.js
node --test
```
